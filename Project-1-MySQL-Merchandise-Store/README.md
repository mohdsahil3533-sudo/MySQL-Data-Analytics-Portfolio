# 🛍️ Merchandise Store Database — MySQL

A **MySQL database project for a merchandise store for coders**, selling coding-themed hoodies, mugs, stickers, notebooks, T-shirts, and other accessories. 💻

This project demonstrates practical use of **relational database design, table relationships, foreign keys, realistic demo data, and business-oriented SQL analysis**. 📊

---

## 📌 Project Overview

The database is designed to manage:

* 👤 Customers
* 📦 Products
* 🛒 Orders
* 🧾 Order Items
* 💳 Payments

The project uses relationships between these tables to represent a real-world e-commerce workflow, from customer registration and product purchases to orders and payments.

---

## 🔗 Table Relationships

The database follows a relational structure:

```text
Customers
    │
    │ 1 : Many
    ▼
Orders
    │
    │ 1 : Many
    ▼
Order Items
    │
    │ Many : 1
    ▼
Products

Orders
    │
    │ 1 : 1
    ▼
Payments
```

### 🔍 Relationships

* One customer can place multiple orders.
* One order can contain multiple order items.
* One product can appear in multiple order items.
* Each order is associated with a payment record in this demo dataset.
* Foreign keys maintain relationships between related tables.

## 📈 SQL Analysis

The project includes business-style SQL queries to answer practical questions such as:

### 💰 Total Revenue

Calculates total revenue from recorded payments.

```sql
SELECT SUM(amount) AS total_revenue
FROM payments;
```

### 📦 Revenue by Product

Identifies revenue generated by each product from delivered orders.

```sql
SELECT 
    p.product_name,
    SUM(oi.quantity * p.price) AS revenue
FROM order_items oi
JOIN products p 
    ON oi.product_id = p.product_id
JOIN orders o 
    ON oi.order_id = o.order_id
WHERE o.order_status = 'Delivered'
GROUP BY p.product_name
ORDER BY revenue DESC;
```

### 👥 Top Customers by Spend

Finds customers based on their total payment amount.

```sql
SELECT 
    c.name,
    SUM(p.amount) AS total_spent
FROM customers c
JOIN orders o 
    ON c.customer_id = o.customer_id
JOIN payments p 
    ON o.order_id = p.order_id
GROUP BY c.name
ORDER BY total_spent DESC;
```

### 🏆 Best-Selling Products

Identifies products based on the total quantity sold.

```sql
SELECT 
    p.product_name,
    SUM(oi.quantity) AS total_sold
FROM order_items oi
JOIN products p 
    ON oi.product_id = p.product_id
GROUP BY p.product_name
ORDER BY total_sold DESC;
```

### ❌ Cancelled Orders

Counts the number of cancelled orders.

```sql
SELECT 
    COUNT(*) AS cancelled_orders
FROM orders
WHERE order_status = 'Cancelled';
```
